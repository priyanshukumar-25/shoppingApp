# 🛍️ AuraStore - Premium Shopping App Front Page

**AuraStore** is a responsive e-commerce front-page web application featuring dynamic dark/light mode, live product search & filtering, wishlist management, product quick view modals, and a slide-over shopping cart drawer.

---

## 🌟 Key Features

- **🌓 Dark & Light Theme Switcher**: Toggle between sleek dark and vibrant light mode, with preferences automatically saved to `localStorage`.
- **🔍 Live Search & Filter**: Real-time product search bar with instant drop-down recommendations, plus category filter pills (*Electronics, Audio, Wearables, Accessories*).
- **🛒 Interactive Cart Drawer**: Slide-over cart panel allowing quantity adjustment, item deletion, live subtotal & shipping calculation, and checkout simulation.
- **❤️ Wishlist Management**: Toggle favorite items with instant heart animations and persistent state saving.
- **👁️ Product Quick View Modal**: Preview detailed product descriptions, pricing, and ratings without leaving the main page.
- **⚡ Flash Sale Countdown**: Real-time ticking timer for limited-time promotional offers.
- **📱 Fully Responsive**: Tailored grid and flex layouts optimized for mobile, tablet, and desktop screens.
- **📧 Newsletter Discount**: Email subscription form with instant coupon unlock popup (`WELCOME15`).

## 🚀 How to Run Locally

1. Simply open [`index.html`](file:///d:/shoping%20app/index.html) in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
2. No complex build tools, node servers, or npm installation required.

## 💻 Tech Stack

- **HTML5**: Semantic tags, accessibility attributes (`aria-label`, `role`).
- **CSS3**: Custom properties (variables), Glassmorphism, CSS Grid, Flexbox, Keyframe animations.
- **JavaScript (ES6+)**: Object-Oriented design (`ECommerceApp` class), DOM manipulation, `localStorage` persistence.
- **Icons & Fonts**: FontAwesome 6, Google Fonts (`Outfit` & `Plus Jakarta Sans`).
